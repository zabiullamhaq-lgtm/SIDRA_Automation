# Security and private information

No supported-version policy or security response deadline has been established.
Review the source before enabling macros and use a disposable working workbook.
Workbook/sheet protection is an editing control, not encryption. The public
`SIDRA_Owner_Only.txt` is redacted; obtain the unchanged editing password privately
from the owner if advanced workbook editing requires it.

Use GitHub's Report a vulnerability option if private reporting is available.
Otherwise open an issue containing only a request for a private reporting channel;
wait for a maintainer-provided channel before sharing sensitive details. No security
email address has been designated.

Never post tokens, passwords, licence details, client traffic data,
proprietary models, internal paths or screenshots containing them. Output workbooks,
model links, CSV logs and diagnostics can retain sensitive data. Review those files
separately before sharing. If a credential is exposed, rotate/revoke it through
its issuer; deleting a file or adding `.gitignore` does not remove history/copies.
