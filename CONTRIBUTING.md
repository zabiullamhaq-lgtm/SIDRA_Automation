# Suggestions and contributions

Suggestions are welcome. Use the Suggestion issue template to describe the user
need, proposed behavior and a small synthetic example. Use Bug report for a
reproducible failure. Documentation improvements are welcome too.

For source changes, edit `vba/SIDRAAutomation.bas`, keep changes focused and retain
legitimate attribution. State what you actually checked: source review, Excel
compilation and/or licensed SIDRA processing, with exact versions and bitness.
There is no automated VBA test suite supplied; a static check is not a runtime test.

Submit only work you are entitled to contribute. Contributions intentionally
submitted for inclusion are offered under Apache-2.0 unless explicitly agreed
otherwise. Do not include client workbooks/models, passwords, licence keys, SDK
binaries, internal paths, or fabricated author/co-author attribution. Use synthetic
data and review the explicit files you stage. Keep the public developer note
redacted; do not add the private editing password.
